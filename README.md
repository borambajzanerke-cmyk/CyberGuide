# CyberGuide (Кибергайд)

Ақпараттық қауіпсіздік негіздерін меңгеруші студенттер мен пайдаланушыларға арналған компьютерлік қауіпсіздік бойынша электрондық анықтамалық және оқу құралы.

## Команда құрамы
* **Авторы / Әзірлеуші:** Жанерке Борамбай (барлық рөлдерді атқару: тимлид, аналитик, backend және frontend әзірлеуші, тестілеуші, DevOps).

## Қолданылған технологиялар
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (сыртқы фреймворктарсыз таза код).
* **Backend:** Node.js, Express.js.
* **Дерекқор (ДҚ):** SQLite (`cyberguide.sqlite`), құрылымы `schema.sql` арқылы.

## Ортаға қойылатын талаптар
* Орнатылған **Node.js** (16.x немесе одан жоғары нұсқасы).

## Орнату және іске қосу бойынша қадамдық нұсқаулық
1. Репозиторийді клондау немесе жобаны компьютерге жүктеп алу.
2. Жобаның негізгі (түбірлік) папкасында терминалды ашу.
