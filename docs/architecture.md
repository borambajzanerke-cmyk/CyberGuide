# Жоба архитектурасы — CyberGuide

## 1. Жүйенің жалпы құрылымы
Қосымша клиент-серверлік архитектура бойынша құрылған:

[ Браузер (Frontend: HTML5, CSS3, Vanilla JS) ]
                     │
                     ▼  HTTP / REST API (JSON)
[ Сервер (Backend: Node.js + Express.js — server.js) ]
                     │
                     ▼  SQL сұраныстар
[ Дерекқор (SQLite — cyberguide.sqlite) ]

## 2. Папкалар мен файлдар құрылымы
* `index.html` — негізгі пайдаланушы интерфейсі және беттер құрылымы.
* `style.css` — қосымшаның визуалды стильдері мен бейімделгіш дизайны.
* `script.js` — клиенттік логика, тіл ауыстыру, іздеу және тест нәтижелерін өңдеу.
* `server.js` — Express.js веб-сервері, маршруттар (API) және дерекқормен байланыс.
* `schema.sql` — SQLite дерекқор кестелерін құруға арналған SQL-скрипт.
* `seed-data.json` — бастапқы анықтамалық материалдар мен сұрақтар жиынтығы.
* `cyberguide.sqlite` — жобаның реляциялық дерекқор файлы.

## 3. Дерекқор құрылымы
Дерекқор негізгі келесі кестелерден тұрады:
* **`users`** — тіркелген пайдаланушылар туралы ақпарат (`id`, `username`, `password`, `role`).
* **`articles` / `topics`** — компьютерлік қауіпсіздік бойынша тақырыптар мен теориялық материалдар (қазақ және орыс тілдерінде).
* **`questions` / `results`** — тестілеу сұрақтары, жауап нұсқалары және пайдаланушылардың тест нәтижелері.

## 4. Негізгі серверлік маршруттар (API Endpoints)
* `GET /` — негізгі HTML бетін қайтарады.
* `POST /api/register` — жаңа пайдаланушыны жүйеге тіркеу.
* `POST /api/login` — пайдаланушыны тексеру және жүйеге кіргізу.
* `GET /api/articles` — анықтамалық материалдар тізімін алу.
* `POST /api/results` — тестілеу нәтижесін дерекқорға сақтау.
