# Әзірлеу үдерісі және рөлдерді бөлу — CyberGuide

## 1. Жобадағы рөлдер мен орындалған міндеттер
Жобаны бір әзірлеуші (Жанерке Борамбай) толық цикл бойынша барлық рөлдерді біріктіре отырып орындады:

| Рөл | Орындалған негізгі міндеттер | Нәтиже (Артефактілер) |
| :--- | :--- | :--- |
| **Тимлид (Team Lead)** | Жоба құрылымын жоспарлау, мерзімдерді бақылау, репозиторийдегі тәртіпті қадағалау. | Репозиторий құрылымы, `README.md`, `docs/process.md` |
| **Аналитик** | Пайдаланушы сценарийлерін (С-1..С-3), функционалдық және функционалдық емес талаптарды құрастыру. | `docs/tz.md` |
| **Архитектор / Backend** | Клиент-серверлік логиканы жобалау, SQLite дерекқорын құру, Express.js API маршруттарын жазу. | `server.js`, `schema.sql`, `cyberguide.sqlite`, `docs/architecture.md` |
| **Frontend әзірлеуші** | Екі тілді пайдаланушы интерфейсін версткалау, іздеу және тестілеу логикасын іске асыру. | `index.html`, `style.css`, `script.js` |
| **Тестілеуші (QA)** | Сценарийлер бойынша тест-кейстер құру және қосымшаны браузерде тексеру. | `docs/testing.md` |
| **DevOps** | Жергілікті ортаны баптау, тәуелділіктерді басқару, GitHub репозиторийіне жүктеу. | `package.json`, `.gitignore`, GitHub репозиторийі |

## 2. Git және GitHub-пен жұмыс істеу тәртібі
* Барлық бастапқы код пен құжаттама `main` негізгі тармағында (branch) сақталады.
* `.gitignore` файлы арқылы `node_modules` папкасы мен уақытша файлдар репозиторийде сақталмайды.
* Әрбір логикалық өзгеріс (кодты жүктеу, артық архивтерді тазалау, `README.md` жаңарту, `docs/` құжаттамасын қосу) жеке коммиттер (commits) арқылы тіркелді.
