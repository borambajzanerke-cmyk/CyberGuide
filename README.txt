# CyberGuide с SQL (SQLite)

## Запуск в VS Code

1. Установи Node.js (если ещё не установлен).
2. Открой папку проекта в VS Code.
3. В терминале выполни:
   ```bash
   npm.cmd install
   npm.cmd start
   ```
4. Открой в браузере `http://localhost:3000`.

При первом запуске сервер создаст `cyberguide.sqlite` и перенесёт в неё исходные статьи и вопросы теста из `seed-data.json`. Далее данные читаются из SQLite через `/api/data`.

**Важно:** не запускай `index.html` двойным кликом и не используй Live Server для этого варианта — нужен Node-сервер, потому что браузер не может напрямую обращаться к SQLite-файлу.

## Таблицы

- `articles` — статьи справочника (RU/KZ).
- `quiz_questions` — вопросы теста.
- `quiz_options` — варианты ответов для вопросов.
- `users` — зарегистрированные пользователи; пароли хранятся только в виде криптографических хешей.
- `sessions` — серверные сессии входа.

Файл `schema.sql` содержит структуру таблиц. База `cyberguide.sqlite` создаётся автоматически при первом `npm start`.

Тест расширен до 20 вопросов на русском и казахском языках. При перезапуске сервер автоматически добавляет недостающие вопросы в уже существующую SQLite-базу. localhost доступен только на твоём компьютере; для публичной ссылки нужно развернуть приложение на хостинге и подключить постоянное хранилище SQL.


## Регистрация и вход

На стартовом окне выбери «Войти (С аккаунтом)». Внутри формы можно переключиться между входом и регистрацией. Логин: 3–32 символа (буквы, цифры, подчёркивание или дефис); пароль: 8–128 символов. После регистрации аккаунт и хеш пароля сохраняются в SQLite, а вход держится в HttpOnly cookie до 7 дней. «Как гость» по-прежнему открывает сайт без аккаунта.
